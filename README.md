# OOPS Banner App

A small Java console program that renders the letters O, O, P, and S using text patterns.

## Requirements

- JDK installed
- `java` and `javac` available on your PATH

## Compile and run

```bash
javac Program.java
java Program
```

## Run the lightweight tests

The project uses a dependency-free Java test runner:

```bash
javac Program.java ProgramTest.java
java ProgramTest
```

The test runner checks pattern row counts, row widths, and the combined banner output. It prints `All banner tests passed.` if all assertions succeed.
